# Subway Surfers Clone (Python / Pygame)

Совместный проект "Subway surfers" на Python, используя библиотеку pygame

Участники проекта: Арефин Михаил, Мочалов Эдуард

## Управление
* **A / D** или **Стрелки влево / вправо** — смена полосы
* **W / Пробел / Стрелка вверх** — прыжок (перепрыгивание низких барьеров)
* **S / Стрелка вниз** — присед (проход под высокими барьерами)
* **R / Пробел** — рестарт после проигрыша

## Запуск
```bash
pip install pygame-ce
python main.py
